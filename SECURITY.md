# Reporting a security problem

Please don't open a public issue for a security problem. Report it privately on GitHub: on this repository's
**Security** tab, click **Report a vulnerability**. Only BikeApp sees the report.

Tell us:

- which version of Bike (Settings › Instance shows it) and how it runs (the compose file from a release, or changed);
- what an attacker can do, and the steps to show it;
- anything you have found that limits it, or a fix you suggest.

We answer within three working days, say what we will do and when, and credit you in the release notes if you
wish. Fixes come in a new release; `sh update.sh <version>` installs it (docs/update.md).

The newest release is the one that gets fixes.
